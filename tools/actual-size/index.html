100mm実寸印刷チェック

A4のテストPDFを印刷して定規で測り、プリンターの自動縮小や用紙設定を確認できます。

A4テストPDF

横線100mm・縦線100mm・50×50mmの正方形を描きます。

印刷設定は「実際のサイズ（100%）」を選んでください。

印刷後に測る場所

横線：100mm

縦線：100mm

正方形：50×50mm

家庭用プリンターや定規の誤差は生じます。精密校正用ではありません。

縮小されてしまう場合

印刷画面の「用紙に合わせる」「印刷可能領域に合わせる」などを確認し、PDFサイズと実際のA4用紙が一致しているかをチェックします。
